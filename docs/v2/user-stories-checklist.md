# User stories checklist — US-022 header, US-021 footer, US-023 hero

Generated by `import-work/v2/build_checklist.py` (items) and `import-work/v2/evaluate.mjs` (status). Every acceptance
criterion, dialog field (`DF-*`), variant (`VAR-*`) and normative anatomy / state / NFR statement (`AN-*`, `ST-*`, `NFR-*`)
of the three stories is one item; split criteria get a / b / c suffixes. Status: pass, partial, FAIL, n.a.;
compliance = (pass + 0.5 partial) / (items − n.a.). Evidence: measured on the rendered page (Playwright probes at
320 / 375 / 744 / 1024 / 1280 / 1440 / 1920 + states, axe-core) and on the code at the V1 / V2 git refs.

- V1 = `/content/intact/en/personal-insurance` (Figma page only), eds-intact `2da0a57`, aem-intact `f25d5ee`
- V2 = `/content/intact/en/personal-insurance-v2` (stories applied), current `main` of both repos
